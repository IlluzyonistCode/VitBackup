# VitBackup

> *Secure your data, automate your peace of mind.*

![JSON](https://img.shields.io/badge/JSON-000000.svg?style=flat-square&logo=JSON&logoColor=white)  ![Python](https://img.shields.io/badge/Python-3776AB.svg?style=flat-square&logo=Python&logoColor=white)

## Overview

VitBackup is an automated backup solution with encryption and flexible storage targets. It protects project data through scheduled, encrypted snapshots that can be directed to local storage or remote destinations, with minimal configuration required.

## Getting Started

### Prerequisites

- Python 3.10+ / Node.js 18+ *(depending on the stack above)*

### Installation

```sh
git clone "https://github.com/IlluzyonistCode/VitBackup
cd VitBackup"
pip install -r requirements.txt
```

### Usage

```sh
python main.py
```
